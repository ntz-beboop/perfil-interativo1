# perfil interativo
Este projeto consiste em um perfil pessoal interativo desenvolvido com tecnologias web fundamentais. O objetivo foi criar uma experiência imersiva que vai além do currículo estático, permitindo que o usuário explore informações, habilidades e projetos de forma dinâmica e intuitiva.

A aplicação funciona como um hub centralizado, unindo design responsivo, animações fluidas e manipulação de eventos em tempo real para apresentar uma identidade profissional sólida e moderna.
